# 12 · 组合层（怎么买）

> 目录：[sequoia_x/portfolio/](../sequoia_x/portfolio/) · 入口：`python scripts/build_portfolio.py`
> 一句话：策略决定**买什么**，这一层决定**买多少**。

---

## 1. 为什么需要这一层

8 个策略各自输出 Top-N，互不知情。直接照着买有三个问题：

| 问题 | 后果 |
|---|---|
| **重复下注** | 同一只票被 3 个策略选中，实际仓位被动放大 3 倍 |
| **风险集中** | 30 只可能全是同一行业/同一风格，组合波动远高于单票波动 |
| **等权不合理** | 高波动小盘股和低波动大盘股同权，等于让波动大的票主导盈亏 |

这一层做三件事：**去重 → 定权 → 约束**。它不改选股逻辑。

---

## 2. 定权：波动率倒数

```
w_i ∝ 1 / σ_i        σ_i = 最近 20 个交易日日收益的标准差 × √244
```

为什么用它而不是等权或市值加权：

- **不需要预测收益率**。收益率极难估，波动率相对好估——风险平价的基本前提；
- 等权在波动差异大时会让组合风险被少数高波动票主导；
- 市值加权会系统性超配大盘股，与本项目"选强势股"的目标相反。

代码里还留了 `weighting="equal"` 作为对照组。

> 估不出波动率的股票（上市不足 5 天、数据缺失）**直接不配**。
> 宁可少买一只，也不要瞎给权重。

---

## 3. 约束：单票上限 + 行业上限

| 约束 | 默认 | 说明 |
|---|---|---|
| `max_weight` | 10% | 单票上限 |
| `max_industry` | 25% | 单行业上限，需要行业映射 |
| `total` | 100% | 目标总仓位（可以只建 60%） |

超额权重用 **water-filling** 分配：某只票触顶后，它多出来的额度按比例分给**还有余量**的票，
反复迭代直到收敛。所以：

- 20 只票 + 10% 上限 → 每只约 5%，总仓位 100%；
- **只有 3 只票 + 10% 上限 → 总仓位只能到 30%**，不会硬凑满仓（这是刻意的：约束就是约束）。

行业上限缺失行业数据时**只做单票约束并打 WARNING**——不假装做了行业中性。

---

## 4. 用法

```bash
# 用最新一天的留痕（pick_history）
python scripts/build_portfolio.py

# 指定日期、单票 8%、只用 60% 仓位
python scripts/build_portfolio.py --date 2026-11-23 --max-weight 0.08 --total 0.6

# 等权对照
python scripts/build_portfolio.py --weighting equal
```

实测输出（2026-11-23 留痕，58 只候选 / 5 个策略）：

```
信号日 2026-11-23 · 候选 58 只（5 个策略）· 去重后 54 只
总仓位 100.0% · 单票最大 3.5% · 多策略共识 4 只

代码      名称             权重     年化波动  策略
600926  杭州银行        3.5%    14.2%  rps
601658  邮储银行        3.2%    15.3%  rps, turtle
...
```

注意 `601658 邮储银行` 是 `rps, turtle` 双策略共识——这就是去重生效的地方：
它在两个策略里各出现一次，组合里只保留一份，但 `strategies` 记下了两个来源。

## 5. API

```python
from sequoia_x.portfolio import build, summarize

positions = build(
    {"turtle": ["600000", "000001"], "rps": ["000001"]},
    snap,                      # MarketSnapshot：估波动率 + 取最新价
    max_weight=0.10,
    max_industry=0.25,
    industry={"600000": "银行"},  # 没有就传 None
    total=1.0,
)
print(summarize(positions))   # {'positions': 2, 'gross': 1.0, ...}
```

`Position` 有 `symbol / weight / vol / strategies`，`consensus` 属性是被几个策略选中。

---

## 6. 局限

1. **没有行业数据**：`stock_industry` 表还不存在，行业上限目前不生效（会告警）。
   补数据后自动启用，不需要改组合代码；
2. **没有考虑相关性**：真正的风险平价需要协方差矩阵，这里只用了对角（各票独立）；
3. **没有换手率控制**：每天重算权重会产生不必要的调仓，实际执行时应对"权重变化小于阈值"的
   持仓不做调整；
4. **没有止损**：组合层只管建仓，不管退出；
5. 波动率用 20 日窗口，对刚经历大涨大跌的股票会滞后。
