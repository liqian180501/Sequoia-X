# 16 · 资金监控

> 目录：[sequoia_x/capital/](../sequoia_x/capital/) · 入口：[`scripts/capital_scan.py`](../scripts/capital_scan.py)

---

## 1. 定位：监控，不是选股策略

选股负责"从 5,000 只里挑出值得看的 20~30 只"；资金监控负责回答另一个问题：
**这只票背后有没有大额资金在动？**

刻意**不把它做成策略**：我们已经用 11 年数据验证过，任何信号塞进"每天选 30 只"
都会被 0.2% 往返成本吃掉（见 [13 §8](13-factors.md)）。资金流更适合当**提醒**。

---

## 2. 数据源（可插拔）

| 源 | 口径 | 可用性 |
|---|---|---|
| `proxy` | **代理**：`成交额 × 当日涨跌幅`（money-flow 口径） | ✅ 一直可用（本地库，零依赖） |
| `dragon_tiger` | 同花顺龙虎榜：`net_value` / `buy_value` / `sell_value` | ✅ 公开 API，实测可用 |
| `akshare` | 东财个股资金流：主力/超大单/大单分档（真实口径） | ⏳ 东财网络恢复后启用（插槽已留） |

### 同花顺的资金流接口拿不到

文档里有 `GET /api/a-share/capital-flow/snapshot`（超大单/大单/中单/小单的流入、流出、净额），
但页头标着 **"端内专用 · 同花顺AI客户端可用"**，实测返回：

```
HTTP 200  code=2004
"该数据为同花顺AI客户端专用，前往[同花顺AI客户端]…"
```

**给现有 Key 开权限、甚至开 L2 都不行**——权限在客户端，不在 API。
同花顺体系里真正能编程取数的是 **iFinD 金融数据终端**（另一条产品线，需单独授权）。

## 3. 规则

只用 T 日及之前的数据，因此可以直接拿去实盘：

1. 连续 `--streak` 天 `net_main` **同号**（默认 3 天）；
2. 累计净额绝对值 ≥ `--min-net`（默认 5,000 万）；
3. 可选 `min_ratio`：累计净额 / 累计成交额（跨股票可比，大票小票一视同仁）。

判定逻辑放在 `detect()` 里而非落库时，所以**改规则不用重刷历史**。

---

## 4. 用法

```bash
python scripts/capital_scan.py --source proxy --streak 3 --min-net 30000000
python scripts/capital_scan.py --source dragon --streak 1 --min-net 100000000
```

实测（2026-11-24，龙虎榜）：

```
数据源 dragon_tiger · 连续 1 日 · 累计净额 ≥ 10000 万
命中 12 只（流入 6 / 流出 6）

 代码      名称         累计净额(万)   占成交额  最后日期
 002242  九阳股份         22098      47.5%   2026-11-24
 603662  柯力传感         14551      30.9%   2026-11-24
```

代理源实测（2026-11-23，连续 3 日、≥3,000 万）：命中 65 只（流入 27 / 流出 38），
占比 2%~10% 属正常区间；用 `±1` 当幅度时占比会恒为 100%，那是**错的**——
必须乘涨跌幅，比例才有意义。

## 5. 表结构

```sql
CREATE TABLE capital_flow (
    symbol TEXT, date TEXT,
    net_main REAL,      -- 主力净额（元）：代理口径 = 成交额 × 涨跌幅
    net_large REAL,     -- 大单净额（真实口径才有）
    net_super REAL,     -- 超大单净额（真实口径才有）
    turnover REAL,      -- 当日成交额（元），用于算比例
    source TEXT,        -- proxy / dragon_tiger / akshare
    PRIMARY KEY (symbol, date, source)
);
```

主键含 `source`：**代理指标与真实资金流分开存**，绝不混算。

---

## 6. 局限

1. **代理指标是粗的**：分不出主动买卖，也看不出大单；只能做"资金推动强度"的近似；
2. **龙虎榜只覆盖上榜股票**（通常是异动/涨停/换手异常），不代表全市场；
3. **"大额"没有统一定义**：默认 5,000 万，对大票偏松、对小票偏严，建议配合 `min_ratio` 用；
4. **没有历史回溯**：龙虎榜是当日数据，`capital_flow` 需要每天积累才有连续性；
5. **未接网页/飞书**：目前只有命令行，接入展示是下一步。
